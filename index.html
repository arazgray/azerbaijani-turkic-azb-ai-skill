0. About this project (from README.md)

آذربایجان تۆرکجه‌سی (آذربایجان تۆرکجه‌سینین عرب کؤکلو الیفباسی) دۆزگۆن یازی قایدالارینین AI باشاریغی

This repo provides a complete instruction set (SKILL.md) that makes an AI write and normalize Azerbaijani Turkic (azb) in the Arabic-rooted Turk alphabet, exactly as decided at the 2001 Tehran Arabic-script Turk alphabet seminar led by Dr. Javad Heyat.

  • Exact Unicode vowel mapping: correct initial/medial/final forms — وْ (O), ۇ (U), ؤ (Ö), ۆ (Ü), ئ (E), and the ؽ (Iı) vs ی (İ) distinction — so LLMs stop using lookalike letters.
  • Context-aware vowels: standard running text by default; Iı clarification only for teaching / dictionary / folklore / disambiguation.
  • Consonant preservation: original Arabic consonants (ع ط ص etc.) kept in Arabic-origin words, personal names and frozen phrases; never phoneticized into native Turkic letters.
  • Yumşaq-g + intervocalic k→g: closed-class rules only (§3/5).
  • Ə / E syllable & morphology rules, ZWNJ (U+200C) suffix rules, می/مو and دا/ده handling, hamza / tashdid / tanvin, and SP/ST prothesis with ای.

Why it matters: consistent cross-platform text, standard input logic for custom iOS keyboards, and letter normalization / classification for dictionaries such as “Erk Sözlüğü”.

Culture: Azerbaijani Turkic is an Oghuz Turkic language with deep literature — from Dede Qorqud to Fuzuli, Nasimi, Shah Ismail Khatai and Mohammad-Hossein Shahriar. Its sound harmony and word-building power make it poetic and expressive.

Note from README: that article itself was written entirely by Google Gemini following SKILL.md — proof that the rules work for modern AI and digital platforms.

Iı is not the same as İi. ؽ (U+063D) is the dedicated Iı letter, but it is not the normal running-text spelling. The 2001 manual says the Iı mark does not normally need to be written — use it only for teaching, foreign words, folklore, dictionary titles, or where the spelling must be clarified, or when the user explicitly asks. Thus ordinary prose may use آغیز، قاییق، ایشیغیدیر. Do not “correct” user text that already follows the booklet's printed running forms unless asked to normalize.
Hard substitutions: O is وْ not DAMMA; U is ۇ not DAMMA nor bare و in first syllable; Ö is ؤ; Ü is ۆ; E in native Turkic is ئ; İ/Y is Farsi Yeh ی U+06CC never Arabic Yeh ي U+064A; K is ک U+06A9 never ك; G is گ U+06AF; H is ه U+0647; ZWNJ is U+200C.

3.1 Vowel-mark modes (one mode per text, default = standard)

  • Ordinary running text (default). Light spelling; do not write ؽ / اؽ routinely. Example: آغیز، قاییق، ایشیغیدیر.
  • Iı clarification mode. Dedicated ؽ / اؽ only when Iı vs İ would otherwise be unclear, or for teaching / dictionary / documentation. Examples: قؽز، دؽرناق، اؽلدیریم.
  • Marked / primer mode. When explicitly asked for teaching/primer/folklore marking, write fuller marks (گؤرۆنۆش، اوْغۇز، دۆیۆن).

Word-initial Turkic Iı can be اؽ in clarification/marked spelling, but do not force it into ordinary prose. Words that are actually İ stay ای: ایراق، ایلان، اینام.

Consonants: ب پ ت ج چ خ د ر ز ژ س ش غ ق ف ک گ ل م ن ه و ی — with ی always U+06CC and ک always U+06A9. Parenthesized Arabic letters appear only in Arabic-origin (sometimes Persian) words, never in native Turkic:

  • ط ث ص ظ ذ ض ح ع
  • Native: سالماق، سوْن، ساققال، ترلان، توْیوق، اوْتاق، ماهنی (not صالماق، طرلان، ماحنی)
  • ع is kept in Arabic-origin words (عشق، علم، احسان، مۆعلّیم، مۆعاصیر، منافع) and frozen Arabic phrases — not limited to frozen phrases. Native Turkic never takes ع. Example: علی stays علی, not الی.

3.2 Auxiliary marks

  • FATHA َ U+064E — only to disambiguate unwritten Ə (اَیری، دَیَر، دَوه)
  • KASRA ِ U+0650 — only for E in foreign words when confusion is likely (اِلِمِنت، تِست)
  • SHADDA ّ U+0651 — Arabic-origin only
  • FATHATAN ً U+064B — Arabic tanvin only (مثلاً)
  • SUKUN ْ U+0652 — part of O (سوْن)
  • HAMZA — §8 table only

5. Core spelling rules (with right vs wrong)

Ə — write sparingly (§2.1). Initial ا, end-of-morpheme/syllable ه, omitted mid-morpheme.
دلی، گلمک، گؤزل not ده‌لی، گه‌لمه‌ک، گؤزه‌ل
Cut morphemes/syllables first. One-syllable words ending in Ə write it: نه، ده. Keep root stable: گل / گلن / گلنیم. If ambiguous, add FATHA: اَیری، دَیَر.
E next to Y is always written (§2.2).
مئیل، قئید، سئیر، گۆنئی not میل، قید، شی
Native Turkic: always ئ / ائ (گئتمک، دئدیم). Loans normally omit E except this closed exception.
O/U/Ö/Ü are four codepoints.
سوْن، بۇروق، گؤن، گۆن not سون، بوروق، ترک
Keep documented double-waw after Ö: دؤولت، شؤوکت، دؤوران.
Iı = ؽ only in clarification mode.
قؽز (marked) not routine ؽ in ordinary prose; never قیز for قؽز when contrast matters
Yumşaq g — closed class only (§3/5).
ایگید، ایگیرمی، چیگین، گتیردیگیم not ایگده for اییده; not گؤگرچین، گؤک، دگیرمان
Intervocalic k→g keeps root visible.
چؤرگیم، گله‌جگیم، گؤروندوگو not چؤره‌ییم، گؤروندویو
Shadda/tanvin only in Arabic loans.
ادبیّات، مثلاً not چاقّال (→ چاققال)
Turkic doubles the letter: چاققال، ائششک، دوْققوز. European: اوْتللوْ.
SP/ST… loans take ای.
ایسپورت، ایستالین، خیاوان not اسپورت، خییاوان
Only SP ST ŞP ŞT SK. Do not prepend to پلان، پروگرام — unsettled.

5.1 Consonant details (§3–§5)

  • V = bare و. H = bare ه (همیشه، آللاه; native never ح). Y = bare ی (یایلیق، بایرام، آی).
  • Thick European K = ک not ق: دوْکتور، دموْکراسی.
  • Final Arabic ع pronounced H = ح: ماتاح، طاماح. Medial = ه: فهله.
  • Foreign غ pronounced Q stays غ: غریب، غزل، غم. Persian گ pronounced Q stays گ: کارگاه، دانیشگاه.
  • European loans follow French reading: رداکسیوْن، ناسیونال، انرژی. Latin G that is Q in Latin Azerbaijani = ق: اوْرتوقرافی، قرامر. European ae = آی: آیروپورت.
  • Otherwise phoneticize with Turkic vowels: مۆشکول، ایستیقلال، اینسان، مۆعاصیر، ورزیش، تلویزیون (not مشکل، استقلال، ورزش).
  • Nativized loans are a list, not a converter: مۇغایات، هامبال، باریت، مؽزی، آبیر، آمبار، قایدا، طایفا، فایدا.

6. Suffixes — MUST attach vs MUST ZWNJ vs MAY ZWNJ

ZWNJ = ‌ U+200C. Never replace a prescribed ZWNJ with a space. Never insert ZWNJ where the booklet attaches.

  • MUST attach (no ZWNJ, no space): ordinary suffixes. گلمیشم، گلدیلر، ائللر، گؤزلدیر، اینسانلار، گۆنشلر (not اینسان‌لار).
  • MUST distinguish دا/ده: suffix → attach (منده‌دیر); independent “also” → space (حسن ده گلدی، من ده).
  • MUST write می/مو as juxtaposition, never space: middle → ZWNJ (گلدی‌می؟ گئتدی‌می؟); end → side-by-side with ZWNJ (نه‌سن؟ not نه سن).
  • MUST ZWNJ before suffixes with a linking consonant (§8/4: نین/نؽن، یه/یا، ییک/یؽق، ییر/یؽر، یئف، یئوا):
    موسیقی‌سی، ننه‌نین، علی‌یه، ماهنی‌یا، تانری‌نین، تانری‌یا، یئری‌ییر، تقی‌یئف
    Wrong: تانرینین، تانرییا، یئریییر.
  • MAY ZWNJ: 4+ syllables after vowel-final morpheme (مۇسیقی‌چیلر، بیزیمکی‌لر); same/similar consonant ×3 (سس‌سیز); same letter at joint where first joins from right (نسیل‌لر، منیم‌میش، دیل‌لنمک); if it does not join from right, attach left (اللر، داممیش، گؤللنمک).
  • MUST attach — borrowed formatives (a): کار، خانا، دار، گاه، کده، بئ، پاز، باز، بر، جو، ایزم، پئش، کش، گر، زده، خواه، نامه، زن، خوْر، دان، یستان، زادا، سن، هم، اوْف، اوْوا
    صنعتکار، کیتابخانا، دانیشگاه، پئشواز، غربزده، حسنوف، حسنوْوا
  • MUST ZWNJ — borrowed formatives (b): شۆناس، پرست، طلب، فۆرۇش، آنتی، پرور، پان
    آذربایجان‌شۆناس، وطن‌پرست، شؤهرت‌طلب، آنتی‌کوْمونیست (not آذربایجانشۆناس).

7. Compounds, hamza, names & numbers

7.1 Compounds and phrases

  • Native compounds: parts independent, juxtaposed with ZWNJ, no space: آغ‌ساققال، آغ‌بیرچک، ککلیک‌اوْتو، ایت‌بۇرنو. Do not force ZWNJ into booklet solids: قانۇنااۇیغونلوق، گؤزوگؤتورمزلیک.
  • Foreign compounds: same, ZWNJ: مؤهنت‌افزا، دیل‌آرام، وطن‌پرست.
  • Persian constructs where a part has standalone meaning: hyphen: سیمای-شمس، غیر-مۆمکون، ضیدّ-اینقیلاب.
  • Borrowed و: as-is or with Ü: گشت و گۆذار / گشت ۆ گۆذار.
  • Frozen Arabic phrases keep original spelling: علی‌الخصوص، انشاالله، ماشاالله، الی‌آخر.

7.3 Names, geography, numbers (§11)

  • Non-nativized Persian/Arabic personal names keep original spelling: محمّد، حسین، ابوالقاسم، منوچهر، هیئت.
  • Nativized names are a separate list and may use azb spelling: علسگر، فاطما، حۆسئن، ایرضا، ممّد. Do not auto-convert every name.
  • Geography as used in Iran, adapted where possible: لهیستان، اؤزبکیستان، هیندوستان، لۆبنان، اوْتریش، تۆرکیه، کۆردوستان.
  • Distorted place names: restore when possible: تۇفارقان، سئییدآوا، سایین قالا، سۇلدوز، آخما قایا.
  • Turkic words used in Persian: azb spelling: بوْشقاب، اۆتو، اۇمود، قۇلدور.
  • Numbers: digit + hyphen + suffix. Do not invent extra spellings.

8. South accent & vocabulary (policy — not seminar orthography)

  • Answer in the South (Tabriz) accent — where forms differ, the South form wins. Anchor: سلام correct, سالام never.
  • Never Russian-origin or North-specific everyday loans — use the South equivalent.
  • Prefer Turkic words over Persian/Arabic loans only where still clear; keep the loan where replacement would turn obscure. Intelligibility wins.
  • Apply only when generating / translating free South prose — not when normalizing, quoting, or keeping a given word.

9. Unsettled — do not invent (§12)

  • واو معدوله (deferred by the seminar)
  • Foreign initial clusters outside SP ST ŞP ŞT SK, including پلان، پروگرام، کرونولوژی
  • Unlisted nativized loans (promised to an orthography dictionary)
  • Abbreviations (قیسالتمالار was a seminar topic, not a published rule set)

If asked to settle one of these, state that the 2001 decisions left it open.

10. Pre-output checklist + minimal targets

  1. Class the word. Apply only that class's rules.
  2. Cut morphemes and syllables before spelling Ə.
  3. Word-initial vowel uses the carrier form.
  4. Glyphs: وْ ۇ ؤ ۆ ئ ؽ ی ک. ؽ is marked/clarifying Iı, not default. Scan for ي, ك, unintended ؽ overuse.
  5. E next to Y is written. Ə is not written as ئ.
  6. Yumşaq g and intervocalic ک→گ only in §5 environments.
  7. ع ح ط ض ظ ذ ث ص only in the right loan class — but do not strip ع from Arabic loans.
  8. Hamza / tashdid / tanvin from §7–§8 only.
  9. Suffixes: attach vs ZWNJ vs space by §9. می/مو never uses a space.
  10. Do not analogize unlisted nativized words. If the booklet has no rule, do not fabricate one.

Minimal targets: یار بیزه قوْناق گله‌جک. · حالال چؤرگیم بۇ سۆفره‌نین ایشؽغؽدؽر. · هر گلنی قارداش تانیمازلار. · آتام بۇ آخشام تبریزدن گله‌جک. · عاراقچینین منده‌دیر. / حسن ده گلدی، من ده. · تانری‌نین آدییلا. / تانری‌یا یالوارماق. · هئیأت، جۆرأت، مسأله، رییس، اینشا، منشأ · اینسانلار not اینسان‌لار · آذربایجان‌شۆناس not آذربایجانشۆناس
